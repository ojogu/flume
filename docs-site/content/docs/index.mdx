# Flume

Flume is a media processing API. You send it a source — a video or audio
file — and a pipeline of operations. Flume runs the pipeline and hands you
back the result.

```json
{
  "source": {
    "type": "video",
    "uri": "https://storage.example.com/demo.mp4"
  },
  "pipeline": [
    { "operation": "trim", "params": { "start": "0:00", "end": "0:30" } },
    { "operation": "compress", "params": { "quality": "medium" } }
  ]
}
```

A job is created, processed asynchronously, and you download the final
artifact when it completes. No FFmpeg, no workers, no media infrastructure
to operate.

## What you can do

- **Transform** — trim, cut, compress, transcode, resize, watermark,
  subtitle, mute
- **Combine** — join multiple clips into one file
- **Convert** — extract audio, generate thumbnails and GIFs
- **Extend** — chain any of these together in a single pipeline
