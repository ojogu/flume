## Purpose

Webhooks let you receive real-time HTTP notifications when events occur in Flume — job status changes, step completions, and failures. Instead of polling the API, subscribe to events and get notified instantly.

## How It Works

![How it works](/images/webhook.png)

1. **Subscribe** — Create a webhook subscription with your endpoint URL and event filter
2. **Receive** — Flume POSTs signed JSON payloads to your endpoint when matching events occur
3. **Verify** — Validate the HMAC-SHA256 signature to ensure authenticity

## Key Features

| Feature | Description |
|---|---|
| Event filtering | Subscribe to all events (`*`) or specific types (`job.completed`) |
| Signed payloads | HMAC-SHA256 signature in `X-Signature-256` header |
| Automatic retries | Exponential backoff (10s → 1m → 10m → 1h), max 5 attempts |
| Delivery history | Track status, response codes, and retry attempts |
